# 舱单数据定义

id是主单、分组单或箱货明细唯一字符串编号，parent为空表示主单。节点申报件数、净重和毛重是其完整子树的申报总量，校验时只加直接子节点，避免多层重复计数。包装carton=1件，pallet=10件；重量kg与t统一为kg。件数必须非负整数，净重非负且毛重不得低于净重。
拆并结构采用每节点最多一个父级的有向图；自环、长环、缺父级均阻断封存，保留环路径。不会以平面求和替代逐层校验。
危险品按明确分类与UN编号检查，3类与5.1类禁止同箱；未知分类和缺失编号需复核。此演示规则只覆盖文中三类，不替代运输合规审批。
报关总量只汇总主单，与context.json内的申报件数、净重和毛重逐项比较。重复同值折叠，重复编号冲突全部隔离。原始计数=采纳+隔离+空行+重复表头+重复同值行。
封存需所有图、重量、危险品和采信问题处理完毕。数值均Decimal，对外字符串保留精度，编号不转整数。
拼箱归属按箱号×主单给出件数、净重和毛重：每节点只计自有量（申报减直接子节点合计），同一件货全舱只计一次，箱内各主单归属之和等于箱体总量。核验量为箱内叶子节点合计，与归属总量同屏对照逐层核验，不一致记LAYER_MISMATCH。缺父级或入环的节点不可归属，记UNATTRIBUTED并计入该箱未归属节点数。
箱体实测经overrides.container_actual按箱传入件数、净重、毛重（如{"C001":{"pieces":40,"net_kg":"400","gross_kg":"440"}}），实测与归属总量不符记CONTAINER_MISMATCH，未提供实测记NO_ACTUAL。交接裁决只按可被证据证明的部分出结果：主单需子树逐层平衡、无关系错误、无危险品问题且所在箱无混装禁忌方可交接；箱内全部主单可交接、无未归属节点且实测相符（或未提供实测）裁决整箱交接，存在可交接主单裁决部分交接先放行，否则暂缓交接。未整箱交接的箱数计入封存阻断并参与封存哈希，归属变化会重新改变重量核验与封存结论。
